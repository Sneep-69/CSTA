# Calculateur d'augmentation de salaire

Page statique : simulateur brut / net, évolution du salaire dans le temps, comparaison au SMIC et à l'inflation.

- Aucune donnée n'est envoyée : tout est enregistré dans le stockage local du navigateur de chaque appareil.
- Aucune ressource externe : la page ne contacte que le serveur qui l'héberge.
- Installable sur l'écran d'accueil et utilisable hors ligne après la première ouverture.

Mise à jour : remplacer les fichiers, puis changer `VERSION` dans `sw.js`.
